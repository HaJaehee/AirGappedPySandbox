# 용어집

자료 전체에서 쓰는 용어를 가나다순으로 정리했다. 괄호 안은 영문 표기나 원어다.

| 용어 | 뜻 |
|---|---|
| 경로 검증기 | 파일 도구가 받은 경로를 워크스페이스 안으로 제한하는 부품. 이미 있는 파일과 새로 만들 파일을 다르게 검사한다 |
| 계측 훅 | 커널이 시작될 때 심어 두는 감시 장치. 스레드 예외, 하위 프로세스의 비정상 종료, `os.system` 실패를 사건 장부에 기록한다 |
| 관습적 샌드박스 | 운영체제 수준의 강제 격리 없이, 규칙과 경로 검증, 시간 제한 같은 완화책으로 운영하는 실행 환경. 보안 경계가 아니다 |
| 네임스페이스 | 대화 하나에 대응하는 격리 단위. 네임스페이스마다 커널이 하나 있다. `ns-3fa1` 같은 id를 쓴다 |
| 도구 (tool) | MCP 서버가 LLM에게 제공하는 기능 하나. 이름, 설명문, 입력 스키마로 이루어진다 |
| 도구 예산 (tool budget) | 도구 호출 하나가 응답을 미룰 수 있는 최대 시간. 기본 45초로, 클라이언트의 60초 제한보다 짧게 잡는다 |
| 루프백 (loopback) | 같은 컴퓨터 안에서만 오가는 네트워크 주소(127.0.0.1). 네트워크 어댑터가 없어도 동작한다 |
| 미러 (PyPI mirror) | 공개 PyPI의 패키지를 사내망 안에 복제해 둔 저장소 |
| 사건 장부 (incident ledger) | 예외 없이 지나가는 실패를 커널 안에 모아 두는 목록. 실행이 끝날 때마다 서버가 읽고 비운다 |
| 사전 점검 도구 | 배포 환경에 필수·권장 패키지가 있는지, 커널이 뜨는지, 패키지 인덱스에 닿는지 확인하는 명령줄 도구 |
| 산출물 (artifact) | 코드 실행 중 워크스페이스에 새로 생기거나 바뀐 파일. 응답에 Markdown 링크로 붙는다 |
| 산출물 탐지기 | 실행 전후의 파일 스냅샷을 비교해 산출물을 찾는 부품 |
| 설명문 (description) | 도구에 붙은 설명 텍스트. 모델이 읽고 도구 사용법을 판단하므로 사실상 프롬프트다 |
| 스냅샷 비교 | 폴더 안 모든 파일의 (수정 시각, 크기)를 두 시점에 기록해 달라진 파일을 찾는 방법 |
| 에어갭 (air gap) | 외부 네트워크와 물리적·논리적으로 분리된 상태. 이 자료에서는 인터넷이 없는 사내망을 가리킨다 |
| 예비 커널 (reserve kernel) | 미리 부팅해 두었다가 새 네임스페이스에 넘겨주는 커널. 첫 실행의 부팅 지연을 없앤다 |
| 오프라인 휠 | 인터넷이 되는 곳에서 미리 받아 둔 Python 패키지 파일(`.whl`). 인덱스 없이 설치할 수 있다 |
| 워크스페이스 (workspace) | 입력 파일과 산출물이 놓이는 폴더. 모든 네임스페이스가 공유하고, 커널의 작업 디렉터리다 |
| 유휴 회수 | 일정 시간(기본 30분) 쓰지 않은 네임스페이스의 커널을 종료하는 것 |
| 커널 (kernel) | 코드를 실제로 실행하는 별도 프로세스. 이 시스템에서는 IPython 커널이다 |
| 커널 어댑터 | 커널 하나를 감싸 기동, 실행, 타임아웃 복구, 사건 장부 수거를 맡는 부품 |
| 커널 풀 (kernel pool) | 네임스페이스와 커널의 대응을 관리하고, 예비 커널을 준비하고, 유휴 회수와 개수 상한을 적용하는 부품 |
| 판정 (verdict) | 실행 결과를 서버가 등급으로 매긴 것. `RAN_UNVERIFIED`, `RAN_NO_OUTPUT`, `RAN_WITH_ERRORS`, `FAILED`, `TIMEOUT` |
| 포터블 Python | 설치 과정 없이 폴더째 옮겨 실행할 수 있는 Python 배포판. 이 프로젝트는 WinPython 3.13을 쓴다 |
| 프로브 셀 (probe cell) | 매 실행 직후 서버가 조용히 커널에 보내는 짧은 코드. 사건 장부와 종료 코드를 읽어 온다 |
| ADR (Architecture Decision Record) | 설계 결정 하나를 상태, 맥락, 결정, 결과로 기록한 짧은 문서 |
| AnythingLLM | 여러 LLM에 붙어 채팅과 에이전트 기능을 제공하는 앱. 이 시스템의 MCP 클라이언트다 |
| C4 모델 | 시스템 컨텍스트, 컨테이너, 컴포넌트, 코드의 네 단계로 소프트웨어 구조를 그리는 방법 |
| FastMCP | MCP 공식 Python SDK의 고수준 API. 함수에 데코레이터를 붙여 도구로 만든다 |
| iopub 채널 | Jupyter 커널이 실행 중에 생긴 출력, 결과, 예외, 상태 변화를 방송하는 채널 |
| JSON-RPC 2.0 | JSON으로 원격 호출을 표현하는 경량 규약. MCP 메시지의 형식이다 |
| LRU (Least Recently Used) | 가장 오래 쓰지 않은 것부터 내보내는 교체 방식. 네임스페이스 개수 상한에 쓴다 |
| MCP (Model Context Protocol) | LLM 앱이 외부 도구와 데이터에 접근하는 방식을 표준화한 프로토콜 |
| `msg_id` | Jupyter 메시지마다 붙는 고유 id. 어떤 출력이 어느 요청에서 나왔는지 가려내는 데 쓴다 |
| `next_action` | 도구 응답의 마지막 줄. 모델이 다음에 할 일을 명령문으로 지시한다 |
| sLLM | 규모가 작은 언어 모델(small LLM). 이 프로젝트가 상대하는 사내 모델을 가리킬 때 쓴 표현이다 |
| stdio 전송 | 클라이언트가 서버를 자식 프로세스로 띄우고 표준 입출력으로 메시지를 주고받는 MCP 전송 방식 |
| venv | Python 가상환경. 이 프로젝트는 추가 설치 패키지를 `--system-site-packages` venv에 격리한다 |
| ZeroMQ | 메시지 전달 라이브러리. Jupyter 커널과 클라이언트가 이것으로 통신한다 |
