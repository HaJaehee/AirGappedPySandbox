# ADR-010. 스크립트 실행은 `__main__` 의미론을 따르되 결과를 커널에 남긴다

## 상태 (Status)

채택됨 (Accepted) · 2026-07-23, v0.2.0 · 2026-09-22, v0.5.0에서 구현 방식 개정

관련 결정: [ADR-002](adr-002-persistent-jupyter-kernel.md), [ADR-014](adr-014-write-file-tool.md), [ADR-017](adr-017-execution-verdict.md)

## 맥락 (Context)

워크스페이스에 `.py` 파일이 있고 사용자가 "이 스크립트를 실행해 줘"라고 하는 경우가 있다. 실행 도구만으로 하려면 모델이 `runpy`나 `exec`를 쓰는 코드를 직접 짜야 하는데, 약한 모델은 이런 보일러플레이트에서 자주 틀린다.

사용자가 기대하는 동작은 두 가지다.

- 평소 `python script.py`로 실행할 때처럼 `if __name__ == "__main__":` 블록이 돈다.
- 실행이 끝난 뒤, 그 파일에 정의된 함수와 변수를 후속 질문에서 쓸 수 있다.

### v0.2.0의 결정

파일을 `runpy`로 `__main__`으로서 실행하고, 실행이 끝나면 그 결과 이름공간을 커널의 전역 공간에 합친다. 파일 경로는 반드시 워크스페이스 안이어야 한다.

### v0.5.0에서 발견된 문제

`runpy`는 스크립트가 정상적으로 반환해야 이름공간을 돌려준다. 그런데 파이썬 스크립트의 흔한 마무리인 `sys.exit(main())`은 `SystemExit` 예외를 던진다. 이 예외가 이름공간을 합치는 단계보다 먼저 터지면서 두 가지 문제가 겹쳤다.

- 멀쩡하게 끝난 스크립트가 에러로 보고되었다. IPython은 `SystemExit`를 오류로 알리기 때문이다.
- 스크립트의 함수와 변수가 커널에 하나도 남지 않았다. 도구 설명문이 "실행 후에도 최상위 변수와 함수가 메모리에 남는다"고 약속한 것과 어긋났다.

실제로 `sys.exit(main())`으로 끝나는 스크립트를 실행한 뒤 `main`이 정의되어 있는지 확인하면 `False`가 나왔다.

## 결정 (Decision)

v0.5.0부터 `runpy`를 쓰지 않는다. 파일의 소스를 읽어 컴파일한 뒤, 커널의 전역 공간에서 직접 실행한다.

- IPython의 전역 공간은 이미 이름이 `__main__`이므로 `if __name__ == "__main__":` 블록이 돈다.
- 이름은 바인딩되는 순간 전역 공간에 남는다. 스크립트가 `sys.exit()`로 끝나든 중간에 예외가 나든, 그 시점까지 정의된 것은 모두 남는다.
- 실행하는 동안 `__file__`과 `sys.argv[0]`을 파일 경로로 설정하고, 끝나면 원래 값으로 되돌린다.
- `SystemExit`는 직접 잡아 종료 코드를 기록한다. 코드가 0이거나 없으면 정상 종료, 그 밖의 값이면 `FAILED`로 판정한다([ADR-017](adr-017-execution-verdict.md)).

경로와 형식 검사는 커널에 무엇이든 보내기 전에 한다.

- 파일이 실제로 존재해야 하고, 해석된 실제 위치가 워크스페이스 안이어야 한다.
- 확장자가 `.py`여야 한다(v0.4.0부터 강제).
- `fib.py`, `./workspace/fib.py`, 워크스페이스 안의 절대 경로를 모두 받아 준다.

## 결과 (Consequences)

**좋아진 점**

- 스크립트다운 동작(`__main__` 블록 실행, 종료 코드 존중)과 상태 유지를 모두 얻었다.
- `sys.exit(0)`이 더는 에러로 보고되지 않는다.
- 저장 도구와 짝을 이뤄 "저장하고 실행하기"가 두 번의 단순한 호출로 끝난다([ADR-014](adr-014-write-file-tool.md)).

**치른 비용**

- 스크립트의 최상위 이름이 같은 네임스페이스의 기존 변수를 덮어쓴다. 스크립트 안의 `df`가 대화 중에 불러 둔 `df`를 대체할 수 있다.
- `__file__`과 `sys.argv`는 되돌리지만, 스크립트가 바꾼 그 밖의 전역 상태(작업 디렉터리 변경, 모듈 설정 등)는 그대로 남는다.
- 모듈로서 가져오기(`__main__` 블록을 실행하지 않고 정의만 가져오기)는 지원하지 않는다. 필요하면 선택 인자로 추가하는 방안이 로드맵에 있다.
