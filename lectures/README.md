# 에어갭 Python 샌드박스 교육자료

인터넷이 차단된 폐쇄망 환경의 LLM은 계산을 "기억(학습된 가중치)"에 의존하여 처리합니다. 그래서 숫자가 조금만 복잡해져도 그럴듯하게 틀린 답을 제시하곤 합니다. 이 프로젝트는 사용자 PC에 가벼운 MCP 서버를 띄워, LLM에 계산이 필요할 때 로컬 Python에게 작업을 맡기도록 만들었습니다. 본 교육자료는 이 프로젝트를 교재 삼아 다음 세 가지 핵심 내용을 학습할 수 있도록 구성했습니다.

- 폐쇄망이라는 엄격한 제약 조건 속에서 기술을 선별하고 조합하는 방법
- 하나의 시스템을 정적·동적·배포 관점으로 나누어 명확하게 기술하는 아키텍처 문서 작성법
- 성능이 다소 제한적인 LLM을 대상으로 도구를 설계할 때 마주치는 현실적인 문제와 그에 대한 해법

## 누구를 위한 자료인가요?

프로젝트를 인수인계받아 유지보수할 개발자나, "LLM + 로컬 실행 환경"을 유사하게 구축해 보려는 분들을 염두에 두고 작성했습니다. Python 코드를 읽을 수 있고 프로세스, 스레드, HTTP 수준의 기본 개념을 이해하고 계신다면 충분히 따라오실 수 있습니다. MCP나 Jupyter 커널에 대한 사전 지식이 없으셔도 괜찮습니다. 필요한 개념은 2장에서 차근차근 설명해 드립니다.

## 읽는 순서 안내

처음 접하시는 분은 1장부터 순서대로 읽으시면 됩니다. 3장 본문 곳곳에 관련 ADR 번호가 기재되어 있으니, "왜 이렇게 설계했을까?" 궁금한 대목에서 해당 ADR을 함께 살펴보시기를 권합니다.

이미 소스 코드를 다루어 보신 분이라면 4장과 ADR부터 먼저 읽으셔도 좋습니다. 이 프로젝트에서 가장 많은 개선과 고민이 이루어진 부분이 바로 그곳에 모여 있습니다.

각 장의 마지막에는 "생각해 볼 문제"를 수록했습니다. 정답을 맞히는 시험 문제라기보다는 깊이 있는 토론 주제에 가깝습니다. 스터디 형태로 진행하신다면 장마다 한두 문제를 골라 함께 의견을 나누어 보시기 바랍니다.

## 이 자료의 표기 약속

- 기준 버전은 **v0.7.0**(2026-09-22) 기준입니다. 이후 버전에서는 세부 구현이나 수치가 달라질 수 있습니다.
- 소스 파일명이나 세부 함수명 대신 실행 코어, 커널 풀, 산출물 탐지기 등의 '역할 이름'을 중심으로 설명합니다. 구현 코드를 파일 단위로 직접 추적하고 싶으시다면 저장소의 `wiki/02-components.md`를 참고하시기 바랍니다.
- LLM 및 사용자와 직접 맞닿는 명칭은 외부와의 약속(프로토콜/인터페이스)이므로 원문 그대로 표기합니다. 도구 이름(`execute_python_code`), 상태 값(`RAN_UNVERIFIED`), 환경 변수(`SANDBOX_WORKSPACE`) 등이 이에 해당합니다.
- 다이어그램은 Mermaid로 작성했습니다. GitHub, GitLab처럼 Mermaid 렌더링을 지원하는 환경이나 VS Code(Mermaid 확장 설치 시)에서 열람하시면 시각 다이어그램으로 확인하실 수 있습니다. C4 다이어그램은 Mermaid의 C4 문법을 사용했습니다.

## 출처

본 자료는 저장소의 `wiki/`, `README.md`, `BUILD_PORTABLE_PACKAGE.md`, 최초 요구 명세서인 `CLAUDE.md`, 그리고 Git 커밋 기록을 바탕으로 작성했습니다. ADR은 시스템 설계 당시에 실시간으로 남겨진 문서가 아니며, 커밋 메시지와 위키 등에 흩어져 있던 의사결정의 흔적을 모아 사후에 복원한 기록입니다. 남겨진 근거가 다소 간략한 결정 사항은 해당 ADR 본문에 그 배경을 솔직하게 밝혀 두었습니다.
